## Descripción

Esta tarea representa una introducción práctica a la Programación Orientada a Objetos, aplicando sus fundamentos en la resolución de problemas básicos.

Durante su desarrollo se trabajan distintos métodos para ordenar arrays, permitiendo comprender cómo se organizan y manipulan los datos dentro de un programa. Además de obtener un resultado ordenado, el propósito es analizar el funcionamiento de cada procedimiento y fortalecer el pensamiento lógico mediante la implementación de soluciones claras y estructuradas.

## Objetivos

- Comprender el funcionamiento de los arrays.
- Aplicar métodos para ordenar sus elementos.
- Fortalecer la lógica de programación.
- Escribir código claro, organizado y fácil de comprender.
- Familiarizarse con los fundamentos de la Programación Orientada a Objetos.
